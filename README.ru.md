# 🌍 Happy Nomad

**Превращает экспорт чата экспатов в готовый гайд по стране.**

Закидываешь экспорт Telegram-чата, прогоняешь пайплайн, получаешь структурированный Markdown-гайд — жильё, визы, бюджет, валюта, связь, районы — где каждая цифра с датой и проверена.

Набор портируемых [Agent Skills](https://docs.claude.com/en/docs/agents-and-tools/agent-skills/overview) (`SKILL.md`) плюс рабочие скрипты. Работает с любым клиентом, который читает формат Agent Skills — Claude Code, Codex и другие.

> 🇬🇧 [English version — README.md](README.md)

---

## Зачем

В чатах экспатов лежит самая свежая и практичная инфа по релокации — но она закопана в десятках тысяч сообщений. Движок вытаскивает её в чистый проверяемый гайд, вместо того чтобы листать чат сутками.

Не очередной статичный список «топ-10 городов»: **твой** исходный чат, **актуальные** цены с датами, противоречия помечены, устаревшее отсеяно.

---

## Как это работает — пайплайн из 5 этапов

```text
0. Нарезка    Nushell режет JSON-экспорт на срезы по темам      (скрипты + chat-slicer)
1. Извлечение факты с датами и цитатами                        (chat-analyzer)
2. Раскладка  факты → тематические .md по шаблонам             (guide-builder)
3. Сборка     README — режим guide или personal                (guide-builder)
4. Фактчек    проверка, отсев устаревшего, метки уверенности   (fact-checker)
```

Ключевое — **этап 0**: экспорт на 20 000+ сообщений не влезает в контекст модели. Скрипты сначала режут его по ключевым словам, и модель читает только релевантные куски. Дубли-репосты рекламы схлопываются, известный спам (`scripts/spam.txt`) вырезается на лету.

## Быстрый старт

```bash
# 0. Поставь Nushell (на нём работает слайсер) — https://www.nushell.sh/
#    macOS: brew install nushell · Windows: winget install nushell · cargo: cargo install nu

git clone https://github.com/it-publisher/happy-nomad
cd happy-nomad

# 1. Установи скиллы под свой клиент (пример для Claude Code)
cp -r skills/* ~/.claude/skills/

# 2. Положи экспорт в папку исходников страны
mkdir -p chile_src && cp ~/Downloads/result.json chile_src/result.json

# 3. Нарежь по темам (этап 0) — срезы лягут в chile_src/_slices/
nu scripts/slice.nu chile_src/result.json

# 4. Дай команду агенту
#    «Собери гайд по стране Чили, режим guide, период — последние 6 месяцев»
```

Агент подхватывает скиллы, читает срезы, наполняет шаблоны и прогоняет фактчек.

## Два режима на выходе

| Режим | README | Для чего |
|-------|--------|----------|
| **guide** | `README_guide.md` | публичный обезличенный гайд по стране |
| **personal** | `README_personal.md` | свой переезд — чеклист + план по датам |

Тематические файлы в обоих режимах одинаковые, различается только README.

## Структура репозитория

```
happy-nomad/
├── skills/            # Agent Skills (SKILL.md), ядро
│   ├── chat-slicer/       # этап 0 — предобработка
│   ├── chat-analyzer/     # этап 1 — извлечение
│   ├── guide-builder/     # этапы 2–3 — раскладка + сборка
│   └── fact-checker/      # этап 4 — проверка
├── scripts/           # slice.nu (слайсер на Nushell) + ключевые слова + стоп-лист спама
├── templates/         # скелет папки страны (2 режима README + стабы тем)
├── examples/argentina/# обезличенный собранный гайд (эталон вывода)
├── agents/openai.yaml # адаптер для Codex (другие клиенты игнорируют)
└── README.md
```

### Гайд и исходники разделены

Пайплайн пишет в две папки на страну, и в этом разделении весь смысл:

```
chile/              # гайд — только Markdown, публиковать безопасно
├── README.md
├── Housing.md
└── ...

chile_src/          # исходники — в gitignore, никуда не уезжают
├── result.json         # сырой экспорт чата (это чужие сообщения)
├── topics.json         # свои регулярки для страны, если нужны
└── _slices/            # промежуточные срезы по темам
```

`*_src/` лежит в `.gitignore`. Сырой экспорт — это тысячи сообщений людей, которые не соглашались на публикацию. Отдельная игнорируемая папка означает, что неосторожный `git add -A` их не заберёт.

## Поддерживаемые источники чатов

- **Telegram Desktop** JSON-экспорт (`result.json`) — первоклассно.
- Другие (Discord, WhatsApp, Reddit): приведи к тому же виду `{ date, text }` — и пайплайн работает. См. `scripts/topics.json`.

---

## Приватность

- Сырые экспорты **в .gitignore** по умолчанию — твои исходные данные не покидают машину.
- Движок убирает личные идентификаторы на этапе извлечения; гайд несёт факты, а не «кто что сказал».
- Пример (`examples/argentina/`) обезличен: без сырого чата и имён.
