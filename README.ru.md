# 🌍 Happy Nomad

**Превращает экспорт чата экспатов в готовый гайд по стране.**

Закидываешь экспорт Telegram-чата, прогоняешь пайплайн, получаешь структурированный Markdown-гайд — жильё, визы, бюджет, валюта, связь, районы — где каждая цифра с датой и проверена.

Набор портируемых [Agent Skills](https://docs.claude.com/en/docs/agents-and-tools/agent-skills/overview) (`SKILL.md`) плюс рабочие скрипты. Работает с любым клиентом, который читает формат Agent Skills — Claude Code, Codex и другие.

> 🇬🇧 [English version — README.md](README.md)

---

## Зачем

В чатах экспатов лежит самая свежая и практичная инфа по релокации — но она закопана в десятках тысяч сообщений. Движок вытаскивает её в чистый проверяемый гайд, вместо того чтобы листать чат сутками.

Не очередной статичный список «топ-10 городов»: **твой** исходный чат, **актуальные** цены с датами, противоречия помечены, устаревшее отсеяно.

---

## Как это работает — пайплайн из 5 этапов

```text
0. Нарезка    Nushell режет JSON-экспорт на срезы по темам      (скрипты + chat-slicer)
1. Извлечение факты с датами и цитатами                        (chat-analyzer)
2. Раскладка  факты → тематические .md по шаблонам             (guide-builder)
3. Сборка     README — режим guide или personal                (guide-builder)
4. Фактчек    проверка, отсев устаревшего, метки уверенности   (fact-checker)
```

Ключевое — **этап 0**: экспорт на 20 000+ сообщений не влезает в контекст модели. Скрипты сначала режут его по ключевым словам, и модель читает только релевантные куски. Дубли-репосты рекламы схлопываются, известный спам (`scripts/spam.txt`) вырезается на лету.

## Быстрый старт

### Через агента

Вставь это в Claude Code, Codex или любой клиент, читающий Agent Skills. Он сам поставит окружение, подгонит конфиг и соберёт гайд — руками ты делаешь только сам экспорт чата.

```text
Собери мне гайд по направлению из экспорта чата экспатов.

Движок: https://github.com/it-publisher/happy-nomad
Склонируй его, установи скиллы из skills/ под мой клиент
и дальше действуй по его README и SKILL-файлам.

Направление: [город или страна]
Режим README: guide
Период актуальности: последние 6 месяцев

Порядок работы:

1. Проверь, установлен ли Nushell — слайсер работает только на нём.
   Команда `nu --version`. Если его нет: поставь сам, если можешь
   (macOS `brew install nushell`, Windows `winget install nushell`,
   иначе `cargo install nu`), а если не можешь — покажи мне точную
   команду под мою систему и дождись, пока я это сделаю.

2. Экспорта у меня ещё нет. Объясни, как его сделать, и отдельно
   назови настройки, на которых все спотыкаются.

3. scripts/topics.json — универсальная база на русском и английском.
   Она ловит общую лексику, но не местную. После того как экспорт
   появится, изучи корпус и допиши в темы то, что реально встречается
   в этом чате: районы и топонимы, местные банки и операторы, сети
   магазинов, названия сервисов и приложений, валюту и её жаргон,
   пограничные переходы. Выводи термины из частотного анализа текста,
   а не из общих представлений о стране.

4. После нарезки покажи счётчики по темам. Если тема набрала мало
   сообщений — скажи прямо, что данных не хватит, и не выдумывай.
   Тему без данных лучше удалить, чем оставить пустой заглушкой.
```

### Ручная установка

```bash
# 0. Поставь Nushell (на нём работает слайсер) — https://www.nushell.sh/
#    macOS: brew install nushell · Windows: winget install nushell · cargo: cargo install nu

git clone https://github.com/it-publisher/happy-nomad
cd happy-nomad

# 1. Установи скиллы под свой клиент (пример для Claude Code)
cp -r skills/* ~/.claude/skills/

# 2. Положи экспорт в папку исходников направления
mkdir -p chile/chile_src && cp ~/Downloads/result.json chile/chile_src/result.json

# 3. Нарежь по темам (этап 0) — срезы лягут рядом с экспортом
nu scripts/slice.nu chile/chile_src/result.json

# 4. Положи стабы тем рядом с исходниками
cp templates/*.md chile/

# 5. Позови агента
#    «Собери гайд по Чили, режим guide, период — последние 6 месяцев»
```

`scripts/topics.json` идёт универсальной русско-английской базой. Допиши в него местное — районы, банки, операторов, сети магазинов, — иначе срезы поймают только общую лексику.

Агент подхватывает скиллы, читает срезы, наполняет шаблоны и прогоняет фактчек.

## Два режима на выходе

| Режим        | README               | Для чего                               |
| ------------ | -------------------- | -------------------------------------- |
| **guide**    | `README_guide.md`    | публичный обезличенный гайд по стране  |
| **personal** | `README_personal.md` | свой переезд — чеклист + план по датам |

Тематические файлы в обоих режимах одинаковые, различается только README.

## Структура репозитория

```
happy-nomad/
├── skills/            # Agent Skills (SKILL.md), ядро
│   ├── chat-slicer/       # этап 0 — предобработка
│   ├── chat-analyzer/     # этап 1 — извлечение
│   ├── guide-builder/     # этапы 2–3 — раскладка + сборка
│   └── fact-checker/      # этап 4 — проверка
├── scripts/           # slice.nu (слайсер на Nushell) + ключевые слова + стоп-лист спама
├── templates/         # скелет папки страны (2 режима README + стабы тем)
├── examples/argentina/# обезличенный собранный гайд (эталон вывода)
├── agents/openai.yaml # адаптер для Codex (другие клиенты игнорируют)
└── README.md
```

### Гайд и исходники разделены

Пайплайн пишет в две папки на страну, и в этом разделении весь смысл:

```
chile/                  # одна папка на направление
├── README.md           # гайд — Markdown, публиковать безопасно
├── Housing.md
├── ...
└── chile_src/          # исходники — в gitignore, остаются у тебя
    ├── result.json         # сырой экспорт чата (чужие сообщения)
    ├── topics.json         # свои регулярки для страны, если нужны
    └── _slices/            # промежуточные срезы по темам
```

`*_src/` лежит в `.gitignore` и матчится на любой глубине, поэтому неосторожный `git add -A` сырой экспорт не заберёт.

Markdown выходит готовым к публикации: этап 4 обезличивает его, заменяя имена участников чата на роли вроде `старожил, 3 года в городе`.

## Поддерживаемые источники чатов

- **Telegram Desktop** JSON-экспорт (`result.json`) — первоклассно.
- Другие (Discord, WhatsApp, Reddit): приведи к тому же виду `{ date, text }` — и пайплайн работает. См. `scripts/topics.json`.

---

## Приватность

- Сырые экспорты **в .gitignore** по умолчанию — исходные данные не покидают машину.
- **Этап 4 обезличивает гайд** до того, как считать его готовым. Имена не выбрасываются, а заменяются ролями — `старожил, 3 года в городе`, `визовый консультант`, — так что видно, чей это опыт, но не видно человека.
- Пример (`examples/argentina/`) обезличен: без сырого чата и имён.
